Sonomzy Writer is the custom publishing interface behind this site.

It uses a focused rich-text editor in the browser, GitHub authentication, a Cloudflare Worker for secure publishing, and GitHub Pages for deployment. Posts are written in the editor and committed straight into the repository without opening a traditional CMS.

I built it because I wanted the simplicity of a writing app without giving up the control of a static site.
